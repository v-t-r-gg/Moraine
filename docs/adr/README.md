# Architecture decision records

ADRs record accepted architectural decisions & their historical context. They
are not user instructions.

Completed milestone names may remain when they explain why a decision was made.
Current behavior belongs in [../../ARCHITECTURE.md](../../ARCHITECTURE.md).

When a decision changes:

* keep the old ADR;
* mark its status as superseded;
* link to the successor;
* update current architecture separately.
