# Moraine Windows demo project

This is a disposable sample for the Windows follow-along. It has one source
file and one check that fails until `greet` includes the name.

There is no `.moraine` directory yet. The demo creates it with
`moraine project init`. Do not treat `examples/run-bundle` in the Moraine
repository as the result of this demo. That directory is a generated fixture
for the file shape.

No tokens, credentials, or private ledgers belong in this project.
